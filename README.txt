DM DEMO WEBSITE
================
This is a static UI prototype based on the screenshots you supplied.

Included:
- Mobile-style login
- Home / game catalogue
- Popular, mini-games and demo Aviator/Cricket cards
- Account page
- Demo deposit and withdrawal screens
- Activity and promotion pages
- Responsive layout for phone and desktop

Safety:
- No real-money betting
- No payment gateway
- No UPI/QR collection
- No bank withdrawal
- Game cards are non-functional visual demos

How to run:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. Tap the bottom navigation buttons.
